## My Project Roles & Contributions
This application was developed as a collaborative academic project. My primary contributions focused on building the frontend experience and driving core data functionalities:

* **UI/UX & Layout Design:** Co-designed the structure, user interface, and visual layout of the application screens.
* **Backend Logic & Event Handling:** Co-developed the operational backend code behind functional buttons to handle user interactions smoothly.
* **Inventory Data Storage:** Programmed the system logic responsible for capturing, processing, and saving newly added inventory items.
